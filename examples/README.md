# API Hero examples

Functional `.api` samples for local try-outs. Open this folder as a VS Code workspace and install API Hero.

| Path | Demonstrates |
| --- | --- |
| `rest/httpbin.api` | Basic GET/POST against httpbin |
| `jsonplaceholder/posts.api` | JSONPlaceholder CRUD-style requests |
| `github/public-api.api` | GitHub public REST (no token required for listed calls) |
| `auth/bearer-demo.api` | `@auth` with a profile you create locally |
| `variables/env-demo.api` | Document + environment variables |
| `assertions/expect-demo.api` | `expect` status/body assertions |
| `collections/demo/` | Mini collection for Collection Runner |
| `openapi/README.md` | How to exercise OpenAPI Import with a public spec |

**Never commit real secrets.** Use Secret Storage via **Manage Authentication** for tokens.
