# API Hero documentation

**API Hero** (`ankitsemwal.api-hero`) is a REST/HTTP client for VS Code. Author `.api` requests, organize collections, manage environments and authentication, assert responses, import OpenAPI, and review run history.

Command IDs remain under the `apiRunner.*` namespace for compatibility. See [release/stable-identifiers.md](./release/stable-identifiers.md).
