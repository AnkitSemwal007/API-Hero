# API Hero 2.3.3 — Release notes

Use this copy for the **VS Code Marketplace** update description and the **GitHub Release** body.

---

## Marketplace (short)

**2.3.3** brings the **Execution Center**, a polished **Live Run Report**, and smoother collection runs — plus dependency and Request Editor UX improvements.

- **Execution** Activity Bar view for live collection-run progress, cancel, and recent runs
- **Live Run Report** updates as requests finish, with a subtle highlight on the active request
- **Collection Run Debugger** — expandable **Details** for the last in-memory run (not History)
- Dependency workflow and Request Editor polish
- Discoverability and terminology improvements across Overview, History, Env/Auth, and Response Viewer
- Marketplace screenshots, banner, and workflow GIF under `images/marketplace/`

No OAuth2, cookie jar, Variable Manager UI, or persistent Run Report.

---

## GitHub Release

### Highlights

- **Execution Center** — Activity Bar **Execution** view for live collection runs (progress, cancel, open report, recent history)
- **Live Run Report** — live row updates and a subtle active-request shimmer while a collection is running
- **Collection execution** — clearer progress UI and a smooth handoff to the finished Run Report
- **Request Editor** — more reliable Method/URL behavior outside form mode; Dependencies panel focus fixes
- **Dependency workflow** — clearer Auto / Manual projections and better collection-order alignment
- **UX polish** — Overview, History, Environment Manager, and Auth Manager hints; consistent Save as Variable labeling
- **Marketplace readiness** — screenshots, banner, social preview, workflow GIF, and docs for **2.3.3**

### Unchanged

- Collection Runner failure policies and core execution pipeline
- Dependency graph / autofill engine semantics
- History persistence model (metadata only; no response bodies)
- `.api` request persistence format
