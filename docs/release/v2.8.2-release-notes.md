# API Hero 2.8.2 — Release notes

**Date:** 2026-08-11  
**Extension:** `ankitsemwal.api-hero` **2.8.2**

## Summary

**2.8.2** adds **Import OpenAPI/Swagger definitions directly from a URL**. Paste a public OpenAPI 3.0/3.1 JSON or YAML HTTP(S) address in the existing Import OpenAPI wizard; API Hero fetches the specification and runs the **same** importer used for local files to generate `.api` requests and collections (Git-first workflow unchanged).

## Highlights

- Local File **or** URL on the wizard Source step
- HTTP/HTTPS only; embedded credentials rejected; no Authorization/Cookie headers sent
- Redirects followed with final-URL validation and a redirect limit
- Local JSON/YAML OpenAPI import unchanged; Swagger 2.0 still unsupported

## Install

**Marketplace:** search **API Hero** or install `ankitsemwal.api-hero` **2.8.2** (when published).

```bash
code --install-extension release/api-hero-2.8.2.vsix
```
