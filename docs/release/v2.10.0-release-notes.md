# API Hero 2.10.0 — Release notes

**Date:** 2026-08-13  
**Extension:** `ankitsemwal.api-hero` **2.10.0**  
**npm CLI package:** `@ankitsemwal007/api-hero` **2.10.0** (binary `apihero`)

## Summary

**2.10.0** ships the headless **`apihero` CLI** as a public npm capability on the same runtime as MCP and the VS Code extension.

## Highlights

1. **npm-installable CLI** — `npm install -g @ankitsemwal007/api-hero` exposes `apihero` (Windows `.cmd` / `.ps1` shims included). Published tarball is a tight allowlist with bundled `dist/cli/main.js`.
2. **CI-safe scenario exits** — CLI treats precondition-skipped steps as failure (exit **1**) without changing ScenarioEngine or MCP semantics.
3. **Node engine** — `engines.node: ">=18"` alongside `engines.vscode`.

## Install

```bash
npm install -g @ankitsemwal007/api-hero
apihero --version
apihero run request Hello --workspace .
```

npm package is **scoped** because unscoped `api-hero` conflicts with existing `apihero` on the registry. Marketplace extension id remains **`ankitsemwal.api-hero`**. Marketplace install still does **not** put `apihero` on PATH.
