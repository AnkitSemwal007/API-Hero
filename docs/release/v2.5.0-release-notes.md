# API Hero 2.5.0 — Release notes

**Authentication Premium UX** and **Scenario Experience** — flagship workflows for secure auth and multi-step API automation.

Suitable for GitHub Releases and VS Code Marketplace update notes.

## Summary

**2.5.0** elevates Authentication and Scenarios from foundation features to polished day-to-day workflows. Existing `.api` files, collections, scenario JSON, and settings remain compatible with **2.4.0**.

## Highlights

### Authentication Premium UX

- Redesigned **Auth Manager** with templates, inline secrets, **Test**, and **Run Login**
- **Login API / Session** lifecycle with tokens in VS Code Secret Storage
- **One-shot Bearer**, **Save as Authentication**, and **collection default** auth
- **Response → Use as Authentication** with confirmation
- Health, Identity, and masked Preview

### Scenario Experience

- **Starter templates** for common workflows
- Scenario Editor palette, request binding, and guided properties
- Last-run status in the Scenarios tree
- Live step status while running; Scenario Report on completion

### Also in this release

- UX clarity around Account Login stubs vs Authentication Login API
- Accessibility improvements in Auth Manager and Scenario Editor
- Expanded unit coverage for auth resolution and scenario binding
- Docs and Marketplace README updated for flagship Auth + Scenarios

## Install

**Marketplace:** search **API Hero** or install `ankitsemwal.api-hero` **2.5.0**.

**From VSIX:**

```bash
npm install
npm run package
code --install-extension release/api-hero-2.5.0.vsix
```

Requires VS Code **1.90+**.

## Not in this release

- OAuth2 / OIDC account Login/Logout
- Cookie jar, GraphQL / gRPC / WebSocket
- Run File (multi-request in one editor)
- Variable Manager UI
- Persistent Collection Run Report storage
- Scenarios Phase 2+ advanced step types
