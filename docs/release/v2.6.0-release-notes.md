# API Hero 2.6.0 — Release notes

**Scenarios progressive disclosure**, **project-store scenario paths**, **Reset Workspace**, and **Collection Run Report failure diagnostics**.

Suitable for GitHub Releases and VS Code Marketplace update notes.

## Summary

**2.6.0** keeps Collections as the primary Activity Bar workflow, discloses Scenarios only when relevant, consolidates scenario files under `.apihero/scenarios/`, and adds a safe Command Palette reset for API Hero workspace data. Existing `.api` files, collections, and settings remain compatible with **2.5.0**. Legacy `.api-hero/scenarios/` folders migrate automatically.

## Highlights

### Scenarios progressive disclosure

- Scenarios view hidden until the workspace successfully loads scenarios or you create one
- Sticky visibility per workspace (including after deleting all scenario files)
- Focus Scenarios does not unlock a hidden view

### Scenario storage

- Canonical path: `.apihero/scenarios/*.scenario.json`
- Automatic migration from `.api-hero/scenarios` (byte-preserving; never overwrites differing canonical files)

### Reset Workspace

- **API Hero: Reset Workspace...** — Command Palette only
- Clears `.apihero`, legacy scenarios, extension-wide request history, related workspace state, and auth secrets for discovered profiles
- Preserves Collections, `.api` request files, collection variables, and project source

### Collection Run Report

- Categorized failure diagnostics (precondition, transport, assertion, extraction, …)
- Clearer Details panel copy from a single diagnostics model

## Install

**Marketplace:** search **API Hero** or install `ankitsemwal.api-hero` **2.6.0**.

**From VSIX:**

```bash
npm install
npm run package
code --install-extension release/api-hero-2.6.0.vsix
```

Requires VS Code **1.90+**.
