# API Hero 2.3.2 — Release notes

Stability and UX patch following **2.3.0** (Collection Run Debugger) and **2.3.1** (Request Editor toolbar).

Use this copy for the **VS Code Marketplace** update description and the **GitHub Release** body.

---

## Marketplace (short)

**2.3.2** improves Request Editor and Environment Manager stability.

- Fixed a global focus bug where clicking any Request Editor input immediately lost focus (Dependencies outside-click)
- Environment rename now keeps selection and secrets in sync (no more “Unknown environment” after rename)
- Method/URL correctly disable outside form mode; Dependencies panel polish and extra regression coverage
- Collection Run Debugger (from 2.3.0) unchanged — expand Run Report Details to inspect the last collection run

No changes to the execution pipeline, dependency engine, or request file persistence.

---

## GitHub Release

### Highlights

- **Request Editor stability** — inputs keep focus on normal click; Method/URL disable in multi/empty modes
- **Focus bug fix** — Depends-on document click no longer steals focus when the popover is closed
- **Environment Manager** — rename sync, selection, ID re-keying, deterministic secret restoration (skip ambiguous pairs)
- **Collection Run Debugger** — still available in the Run Report (last-run, in-memory Details)
- **Regression coverage** — additional tests for focus and environment rename/secrets

### Unchanged

- Collection Runner execution order and failure policies
- Dependency graph / autofill engine semantics
- `.api` request persistence format
