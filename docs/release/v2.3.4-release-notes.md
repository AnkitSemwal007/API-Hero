# API Hero 2.3.4 — Release notes

Use this copy for the **VS Code Marketplace** update description and the **GitHub Release** body.

---

## Marketplace (short)

**2.3.4** is a Marketplace and documentation release. Extension behavior is unchanged from **2.3.3**.

- Redesigned Marketplace README as a scannable product landing page
- Listing media hosted on Cloudinary (CDN URLs; not packed into the VSIX)
- Packaging keeps only required extension assets (chrome icons still ship)
- Docs and release checklists pinned to **2.3.4**

No new features. No OAuth2, cookie jar, Variable Manager UI, or persistent Run Report.

---

## GitHub Release

### Highlights

- **Marketplace README** — hero-first layout, comparison early, features grouped with screenshots beside the sections they describe
- **Cloudinary CDN** — hero, banner, social preview, screenshots, and workflow GIF load from verified HTTPS URLs
- **Leaner packaging** — `images/marketplace/**` excluded via `.vscodeignore` / `.gitignore`; extension icons remain in-package
- **Docs** — CHANGELOG, RELEASE, marketplace readiness / asset mapping updated for **2.3.4**

### Unchanged

- All extension runtime behavior from **2.3.3** (Execution Center, Live Run Report, Collection Runner, Dependencies, Request Editor, etc.)
- Collection Runner failure policies and core execution pipeline
- History persistence model (metadata only; no response bodies)
- `.api` request persistence format

### Install

Marketplace: search **API Hero** (`ankitsemwal.api-hero`).

From VSIX:

```bash
code --install-extension release/api-hero-2.3.4.vsix
```
