# API Hero 2.3.5 — Release notes

**Date:** 2026-07-28  
**Extension ID:** `ankitsemwal.api-hero`

## Summary

**2.3.5** migrates contribution identifiers from the legacy `apiRunner.*` namespace to canonical **`apiHero.*`**, aligning internal IDs with the API Hero brand while preserving compatibility for keybindings, settings, secrets, and open Request Editor tabs.

## Changed

- Canonical command IDs, view IDs, Activity Bar container, settings keys, webview panel types, and auth secret key prefix now use `apiHero.*`
- Legacy `apiRunner.*` command aliases remain registered (and contributed, hidden from the Command Palette) so existing keybindings keep working
- Dual custom editor registration: `apiHero.requestEditor` (default) and `apiRunner.requestEditor` (option)
- One-shot settings migrator copies `apiRunner.*` → `apiHero.*` on activate
- Auth secrets lazily migrate from `apiRunner.auth.profile.*` to `apiHero.auth.profile.*`

## Breaking (layout only)

- Activity Bar container and view IDs are now `apiHero` / `apiHero.collections` / `apiHero.execution` / `apiHero.history`
- Saved sidebar layouts and custom `when` clauses that reference `apiRunner.*` views will not restore those views — reopen the API Hero Activity Bar icon once after upgrading

## Unchanged (intentionally)

- TextMate grammar `scopeName` `source.api-runner` and `*.api-runner` token scopes
- Diagnostic codes `api-runner.*`
- Tree `viewItem` / context values (`collection`, `folder`, `request`, …)
- Domain module naming (`collection-runner`)
