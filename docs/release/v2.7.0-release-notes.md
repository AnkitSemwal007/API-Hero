# API Hero 2.7.0 — Release notes

**MCP for AI coding agents** — discover and run collections without the VS Code UI.

## Summary

**2.7.0** adds a standalone Model Context Protocol (MCP) stdio server that reuses API Hero’s Collection Discovery, Collection Runner, and Execution Orchestrator. Agents such as Cursor, Claude Code, and Codex can list collections, run a collection or single request, and inspect structured failure diagnostics (Expected/Actual, failure category) without opening the Run Report UI. Existing `.api` files, collections, and settings remain compatible with **2.6.0**.

## Highlights

- Eight `apihero_*` MCP tools for discovery and execution
- Headless Node workspace scanner (`Collections/<Name>/`)
- Secret-safe tool JSON (masked headers, JWT/password fields, auth metadata only)
- `api-hero-mcp` bin + `docs/user/mcp.md` client configuration

## Install

**Marketplace:** search **API Hero** or install `ankitsemwal.api-hero` **2.7.0** (when published).

Local VSIX:

```bash
code --install-extension release/api-hero-2.7.0.vsix
```

MCP (from a built checkout):

```bash
npm run compile
node ./dist/mcp/server.js
```

Set `APIHERO_WORKSPACE` to a folder that contains `Collections/`. See [MCP guide](../user/mcp.md).
