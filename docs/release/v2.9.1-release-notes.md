# API Hero 2.9.1 — Release notes

**Date:** 2026-08-12  
**Extension:** `ankitsemwal.api-hero` **2.9.1**

## Summary

**2.9.1** is a documentation and Marketplace presentation patch on top of **2.9.0**:

1. **Restored Marketplace / extension icon** — `images/icon.png` restored to the pre-Cursor version
2. **Complete README / Marketplace coverage** — Diff, TypeScript generation, Failure Diagnostics (Possible causes), Postman / Insomnia / cURL import, and Request Dependencies / data flow documented as product capabilities (shipped in **2.9.0**)
3. **Marketplace description clarity** — import formats called out beyond OpenAPI-only

No new runtime product features are claimed beyond **2.9.0**. Public headless CLI / CI distribution is **not** part of this release.
