# API Hero 2.12.0 — Release notes

**Date:** 2026-08-14  
**Extension:** `ankitsemwal.api-hero` **2.12.0**  
**npm CLI package:** `@ankitsemwal007/api-hero` **2.12.0** (binary `apihero`)

## Summary

**2.12.0** adds VS Code source-code integration (CodeLens, hover, mapped Run / Open / Generate TypeScript), Collection Run Report JSON and standalone HTML export, and portable `.apihero` project packages. Scenarios are no longer a current VS Code product capability. Backward compatible with **2.11.0**.

## Source-code integration

Explicit mappings only:

- `// @api-hero` (or JSDoc) in TypeScript / JavaScript / TSX / JSX
- `@source` on `.api` files

CodeLens actions: **Run Request**, **Open API Definition**, **Generate TypeScript**. Hover and **Open Related Source** use the same mappings. REST and GraphQL requests can be mapped. Ambiguous, deleted, or renamed targets produce no CodeLens.

Execution still uses `ExecutionOrchestrator`. Type generation still uses the existing TypeScript-from-JSON generator.

See [source-code integration](../user/source-integration.md).

## Collection Run Report export

The existing Collection Run Report is unchanged. **Export** writes a redacted snapshot as JSON or standalone HTML. **Run Again** remains available. Secrets are stripped from the snapshot.

Scenario Run Report export is not part of this release.

See [Collection Runner](../user/collection-runner.md).

## Project package v1

**API Hero: Export Project** / **Import Project** write and restore a single `.apihero` file (internal ZIP via `fflate`; users do not unzip it).

Included: Collections, `.api` files (nested structure and supported legacy files), environments, variables, project configuration, auth profile metadata.

Excluded: secrets, `.apihero/local/`, Scenarios, caches, `.git`, `node_modules`.

v1 is VS Code-only. Desktop, CLI, and MCP package commands are not included. Signing and encryption are not included. Import does not restore secrets.

See [project package](../user/project-package.md).

## Scenario product status

Scenarios are not a current user-facing VS Code capability. Use Collection Runner for multi-request runs. Historical changelog entries for earlier releases remain unchanged.
