# API Hero 2.8.1 — Release notes

**Complete product README / public documentation** — Marketplace landing page + developer reference; release packaging pin for universal standalone MCP.

## Highlights

**2.8.1** ships a full rewrite of the public README as the authoritative Marketplace and developer reference: requests, collections, variables, authentication, assertions, Collection Runner, history, scenarios (advanced), OpenAPI, and MCP tools/config/security. Documentation corrects storage paths (request history under VS Code **globalStorageUri** as `request-history.json`; scenarios under `.apihero/scenarios/`) and stresses **client-owned** MCP registration — installing the VS Code extension does **not** auto-register the server with Codex, Cursor, or Claude. Runtime behavior remains backward compatible with **2.8.0**.

## What shipped

- Complete README rewrite (Marketplace + developer reference)
- Client-owned MCP configuration documented (`--workspace` priority; no auto-registration)
- Corrected history / scenarios storage documentation
- Release readiness and MCP path examples pinned to **2.8.1**

## Install

**Marketplace:** search **API Hero** or install `ankitsemwal.api-hero` **2.8.1** (when published).

Local VSIX:

```bash
code --install-extension release/api-hero-2.8.1.vsix
```

MCP (from a built checkout or installed extension):

```bash
node ./dist/mcp/server.js --workspace "/absolute/path/to/your-api-workspace"
```

See [MCP guide](../user/mcp.md).
