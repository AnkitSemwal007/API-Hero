# API Hero v1.0 — VS Code Marketplace Release Checklist

Step-by-step checklist for publishing **API Hero** `ankitsemwal.api-hero` **1.0.0** to the Visual Studio Code Marketplace.

**Baseline (as of this doc):** working tree is **1.0.0** (Phase 1 complete). Prefer this repo’s scripts over generic `vsce` advice.

| Item | Value |
| --- | --- |
| Extension ID | `ankitsemwal.api-hero` |
| `package.json` `name` / `publisher` | `api-hero` / `ankitsemwal` |
| Current version | **`1.0.0`** |
| License | MIT (`LICENSE`) |
| Entry | `./dist/extension.js` |
| Icon | `images/icon.png` (128×128 PNG) |
| Gallery banner color | `#0f766e` / `theme: dark` |
| Packaging | `@vscode/vsce` via `npm run package` (clean → build → test → `release/api-hero-<version>.vsix`) |
| Prepublish | `vscode:prepublish` → `npm run compile` (`tsc -p ./`) |

**Related docs:** [marketplace-readiness.md](./marketplace-readiness.md) · [marketplace-assets.md](./marketplace-assets.md) · [stable-identifiers.md](./stable-identifiers.md) · [banner-placeholder.md](../marketplace/banner-placeholder.md) · [`RELEASE.md`](../../RELEASE.md) (operator runbook: version bump → lint/test/build → `npm run package` → manual portal upload)

**Release method:** Package with `npm run package`, then **manual VSIX upload** in the [Visual Studio Marketplace publisher portal](https://marketplace.visualstudio.com/manage). This project does **not** use `npx vsce publish` as the primary path (PAT/auth issues).
