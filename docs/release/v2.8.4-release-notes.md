# API Hero 2.8.4 — Release notes

**Date:** 2026-08-12  
**Extension:** `ankitsemwal.api-hero` **2.8.4**

## Summary

**2.8.4** polishes everyday VS Code workflows on the same execution core:

1. **OpenAPI environment safety** — preserve the active environment on import; keep imported envs selectable; warn on undefined security schemes without inventing auth
2. **Collection Run Report UX** — compact summary/rows, filters, folder grouping, and drill-down Details
3. **Variable Trace UX** — compact Variables status; expand for full trace / unresolved
4. **Scenario menu cleanup** — Create Scenario removed from Collections top-level `…`; dedicated Scenario UX unchanged

## Highlights

- DummyJSON (or any active env) stays selected when importing another OpenAPI spec (e.g. OpenAI)
- Run Reports stay scannable on large collections; Details still hold Response, Assertions, Variables, and diagnostics
- Nine MCP tools remain available (including `apihero_run_scenario`); Copy as cURL continues to work
- Public headless CLI / CI distribution is **not** part of this release (implementation retained in-repo only)

## Install

**Marketplace:** search **API Hero** or install `ankitsemwal.api-hero` **2.8.4** (when published).

```bash
code --install-extension release/api-hero-2.8.4.vsix
```
