# API Hero 2.9.0 — Release notes

**Date:** 2026-08-12  
**Extension:** `ankitsemwal.api-hero` **2.9.0**

## Summary

**2.9.0** ships import round-trips, diagnostics polish, response tooling, and leaner packaging on the same REST/HTTP execution core:

1. **Postman Collection import** — Collection v2 / v2.1 → Collections + `.api` via the shared import pipeline; preview + diagnostics (scripts never executed)
2. **Insomnia export import** — Resource-based export v3 / v4 → Collections + `.api` on the same pipeline
3. **cURL → `.api`** — In-process curl parse (never via shell) → single `.api` file; completes the Copy as cURL round trip
4. **Variable Autocomplete polish** — Scope / environment labels, secret-safe detail, catalog refresh on collection/env changes
5. **Failure Diagnostics Possible causes** — Deterministic status/transport explanations on Request Editor, Run Report Details, and MCP diagnostics fields
6. **Request/Response Diff** — Compare Previous vs Current (in-session) and Compare Runs from Collection Run Manager
7. **TypeScript Type Generation** — Infer types from one successful JSON body; Copy or Create `.ts`
8. **VSIX esbuild bundling** — Minified CJS entry bundles; VSIX ~659 KB / 21 files (vs ~4 MB unbundled)

## Highlights

- Import wizards for OpenAPI, Postman, and Insomnia share a parameterized host (preview, cancel, workspace allowlist)
- Sensitive headers stay masked; cURL import replaces secret headers with placeholders in written `.api` files
- Diff and TypeScript generation operate on already-redacted `ResponsePresentation` only
- Public headless CLI / CI distribution is **not** part of this release (implementation retained in-repo only)
- **Not claimed:** GraphQL, gRPC, WebSocket, Swagger 2.0, OAuth2/OIDC live flows, Cookie jar, Postman/Insomnia script execution
