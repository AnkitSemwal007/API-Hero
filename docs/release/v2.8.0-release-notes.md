# API Hero 2.8.0 — Release notes

**Universal MCP workspace configuration** — prefer `--workspace` for any MCP client; clearer Codex / Cursor / Claude setup.

## Highlights

**2.8.0** improves the standalone Model Context Protocol (MCP) stdio server so agents can point at an API Hero workspace with an explicit `--workspace` flag (preferred over `APIHERO_WORKSPACE`). Documentation now stresses **client-owned** MCP registration: installing the VS Code extension does **not** auto-register the server with Codex or other clients. Existing `.api` files, collections, settings, and the eight `apihero_*` tools remain compatible with **2.7.0**.

## What shipped

- CLI `--workspace` / `--workspace=<path>` with fail-fast on missing values
- Workspace resolve priority: `--workspace` → `APIHERO_WORKSPACE` → cwd
- MCP guide updates for Codex (`~/.codex/config.toml`), Cursor, Claude, troubleshooting
- No automatic MCP registration; no second execution engine

## Install

**Marketplace:** search **API Hero** or install `ankitsemwal.api-hero` **2.8.0** (when published).

Local VSIX:

```bash
code --install-extension release/api-hero-2.8.0.vsix
```

MCP (from a built checkout or installed extension):

```bash
node ./dist/mcp/server.js --workspace "/absolute/path/to/your-api-workspace"
```

See [MCP guide](../user/mcp.md).
