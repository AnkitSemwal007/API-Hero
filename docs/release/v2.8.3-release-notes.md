# API Hero 2.8.3 — Release notes

**Date:** 2026-08-11  
**Extension:** `ankitsemwal.api-hero` **2.8.3**

## Summary

**2.8.3** ships three distribution/productivity surfaces on the same execution core:

1. **Headless CLI / CI** (`apihero`) — run request, collection, or scenario from the terminal without VS Code
2. **Copy as cURL** — resolve variables + auth and copy a redacted POSIX cURL command
3. **MCP `apihero_run_scenario`** — run Scenarios through the existing ScenarioEngine (same path as UI)

## Highlights

- Shared headless composition for MCP + CLI (ProjectStore environments, process-env secrets)
- CI-friendly exit codes (`0`–`4`) and `--json` output
- Nine MCP tools (adds `apihero_run_scenario`)
- Secrets redacted in CLI / MCP / cURL by default

## Install

**Marketplace:** search **API Hero** or install `ankitsemwal.api-hero` **2.8.3** (when published).

```bash
code --install-extension release/api-hero-2.8.3.vsix
```

CLI (after install/link):

```bash
apihero --version
apihero run scenario checkout --environment staging
```
